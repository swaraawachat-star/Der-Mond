

# Crescent Moon Keychain


Der Mond is a 3D-printed crescent moon keychain designed using Onshape for the Fallen Trinket Weekend Activity. On one side there is a realistic looking crescent moon and on the other side there is a detailed design of a moon and antlers.
This item has:
-  A crescent shaped moon body
-  Recessed lunar craters in varying sizes
-  Deer antler detailing on the reverse side
-  Small crescent detail between the antlers
-  Circular keyring holder

The design was created using Onshape, with PLA as the intended material and FDM 3D printing as the manufacturing method.
